# Toshiba Stock Management System

This is a stock management system built with Python using Tkinter for the graphical user interface (GUI) and PyMySQL for database management. The system allows you to manage stock items for a business, track stock movements, and maintain records such as item ID, name, price, quantity, category, and description.

## Features

- Add, update, delete, and search stock records.
- Manage stock item details like item ID, item code, name, price, quantity, category, and description.
- Maintain an audit trail of stock transactions with balance updates.
- Store data in a MySQL database.
- Export stock data to CSV files.

## Technologies Used

- **Python**
- **Tkinter** (GUI)
- **PyMySQL** (MySQL database interaction)

## Setup Instructions

### Prerequisites

Ensure that you have the following installed on your machine:

- Python 3.x
- MySQL Server
